# Client Finder

Aplicación web desarrollada con Laravel + React para la búsqueda rápida de clientes mediante nombre, DNI o matrícula.

## Tecnologías

- Laravel 12
- React
- Bootstrap 5
- SQLite
- Git

## Funcionalidades

- Buscar por nombre
- Buscar por DNI
- Buscar por matrícula
- Importar clientes desde Excel
- Diseño responsive
