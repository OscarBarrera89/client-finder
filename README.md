# Client Finder

Aplicación web desarrollada con Laravel 12 y React para localizar clientes y pólizas de forma rápida mediante nombre, identificación, matrícula o número de póliza.

## Tecnologías

- Laravel 12
- React + Inertia
- Tailwind CSS
- SQLite
- Pest para pruebas

## Funcionalidades

- Búsqueda de clientes por nombre o identificación
- Búsqueda por matrícula y número de póliza
- Panel de resultados con pólizas asociadas
- Autenticación y registro de usuarios
- Diseño responsive
